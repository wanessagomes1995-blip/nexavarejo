# NexaVarejo

MVP para cadastro e organização de produtos de pequenos comércios.

## Objetivo

O NexaVarejo busca facilitar o registro e a consulta de produtos, oferecendo uma interface simples e acessível para pequenos comerciantes.

## Funcionalidades

- Cadastro de produtos.
- Registro de nome, categoria, preço e descrição.
- Validação dos dados informados.
- Pesquisa de produtos pelo nome.
- Armazenamento dos dados no navegador por meio do `localStorage`.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.

## Limitações do MVP

Os dados são armazenados no navegador utilizado. Nesta versão, não há banco de dados remoto, autenticação de usuários nem sincronização entre dispositivos.

## Status do projeto

Versão inicial do MVP desenvolvida para demonstrar o cadastro, a organização e a pesquisa de produtos.
